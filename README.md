# Horizon UI

A modern and responsive UI project built with React and Tailwind CSS.

## Features

* Modern UI Design
* Responsive Layout
* React Components
* Tailwind CSS Styling

## Tech Stack

* React.js
* Vite
* Tailwind CSS
* JavaScript

## Installation

```bash
git clone https://github.com/adarshrajshah04/horizon-ui
cd horizon-ui
npm install
npm run dev
```

A clean business-focused landing page UI with a modern design.
